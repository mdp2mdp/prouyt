# Сайт «ПРОУЮТ»: итоговый отчёт

Тестовый адрес: https://mdp2mdp.github.io/prouyt/
Репозиторий: https://github.com/mdp2mdp/prouyt

## 1. Что сделано

- Статический сайт на Astro (чистый CSS, JavaScript около 3,6 КБ на страницу): главная, каталог, 4 раздела, 28 карточек моделей, страница 404, `sitemap.xml`, `robots.txt`. Всего 35 страниц.
- Данные каталога собраны из документа с описаниями и прайса: цены, габариты, характеристики, механизмы. Расхождения между файлами вынесены в `ВОПРОСЫ_ЗАКАЗЧИКУ.md`.
- Фото: оригиналы (230 МБ) переделаны в WebP и AVIF четырёх размеров (480, 960, 1600, 2400 px) без потери заметного качества, вес `public/img` около 34 МБ. Hero использует новое фото 2746 px.
- Дизайн-система в `src/styles/tokens.css` и `DESIGN.md`. Soft-стиль, закреплённый hero с эффектом при скролле (CSS scroll-driven animations и запасной вариант на скролле), плавное появление блоков. Все эффекты отключаются при `prefers-reduced-motion`.
- Каталог: фильтр по механизму (скруглённое меню), галерея со стрелками, миниатюрами, свайпом и клавиатурой, вкладки, блок похожих моделей, таблицы модулей и наборов для «Эстетика».
- Контакты: везде ссылки `tel:+79645106747`, почта `mailto:`, адрес с ссылкой «Построить маршрут» на Яндекс.Карты. Форм, модальных окон и внешних сервисов нет.
- SEO: уникальные `title` и `description`, canonical, Open Graph (для моделей своё превью), разметка `Organization`, `Product`, `BreadcrumbList`.
- Публикация: GitHub Actions + GitHub Pages, инструкция по домену в `docs/DEPLOY.md`.

## 4. Решения, которые я принял сам (до ответа заказчика)

- Размеры Кельна углового, Биг-Бена (прямого) и Николь взяты из прайса, потому что в документе они явно ошибочны (скопированы у другой модели, перепутаны ширина и высота, нет высоты). Остальные расхождения оставлены по документу.
- Цена «от» у «Эстетика» — цена модуля-дивана Д2 (35 290 ₽), а не подлокотника за 7 030 ₽.
- Цена Олимпа взята из строки прайса без названия (определена по размерам).
- Кресла «Версаль» и «Олимп» из прайса в каталог не включены.
- Механизм Оскара П и высота Уники дополнены из прайса.
- Обложки каталога у 5 моделей заменены на собранный вид (на самом большом фото диван был разложен). На фото «Оскар угловой» убрано пятно от удалённой надписи.
- Описания разделов каталога написаны нами (нейтральные).

## 5. Как менять сайт

Все изменения делаются в файлах репозитория и публикуются командой `git push`: сайт соберётся и обновится сам за 1–2 минуты.

| Что менять | Где | Как |
|---|---|---|
| **Цена модели** | `src/data/products.json`, поля `pricePromo` (акционная) и `priceRrp` (обычная) | Поменять число, сохранить |
| **Какие цены показывать** | `src/data/site.json`, `pricing.priceMode`: `"promo"` или `"rrp"` | Одна строка |
| **Текст и характеристики модели** | `src/data/products.json` (поля `description`, `specs`) | Править текст. Если нужно, чтобы правка пережила пересборку из документа, добавить её в `scripts/overrides.json` |
| **Телефон, почта, адрес, юридические тексты, меню** | `src/data/site.json` | Править значения; меню включается и выключается флагом `enabled` |
| **Реквизиты продавца** | `src/data/site.json`, `seller` | Заменить TODO на данные |
| **Описания разделов каталога** | `src/data/categories.json` | Править `description` |
| **Фото модели** | Положить файлы в `_source/проуют диваны фото/<папка модели>/` (в имени студийных фото слово «студ») | Затем `npm run data` и `npm run images` |
| **Включить раздел «Для сна»** | `src/data/categories.json` (`enabled: true`) и добавить товар в `products.json` с `category: "sleep"` | |
| **Фото кресел** | Папка «комфорт» в `_source`, затем `npm run data` и `npm run images`; в `scripts/model-map.json` указать папку в `photoDir` | |
| **Яндекс.Метрика** | `src/data/site.json`, `analytics.yandexMetrika`: `enabled: true` и `id` | Вместе с этим нужны уведомление о cookie и политика конфиденциальности |

Порядок публикации после любых правок:
```bash
npm run audit          # сборка и проверка (необязательно, но полезно)
git add -A
git commit -m "Описание правки"
git push
```

Папка `_source/` (исходные файлы и оригиналы фото) в репозиторий не попадает: её нужно хранить у себя.

## 6. Что ещё важно помнить

- **Домен prouyt.ru.** Файл `CNAME` не создавался. Порядок переключения без остановки старого сайта описан в `docs/DEPLOY.md`.
- **Яндекс.Метрика и cookie.** Сейчас на сайте нет ни аналитики, ни cookie, поэтому баннер и политика не нужны. Если подключите счётчик для рекламы, потребуется уведомление о cookie и политика конфиденциальности.
- **Публичный репозиторий.** GitHub Pages на бесплатном тарифе работает только с публичным репозиторием, поэтому все файлы в нём (включая `ВОПРОСЫ_ЗАКАЗЧИКУ.md`) видны всем. Если это нежелательно, файл можно убрать из репозитория, сайту это не повредит.
- **Ссылка «Построить маршрут»** ищет адрес по тексту, проверьте, что Яндекс ставит метку на производство.
- **Мессенджеры и соцсети.** Если решите добавить, смотрите раздел Д в `ВОПРОСЫ_ЗАКАЗЧИКУ.md` (законные ограничения).
